# Original full-video production

The previous scheduled ce-long workflow stitched past shorts with blurred panels. It is replaced by the original single-topic pipeline, preserving its every-two-days UTC start schedule and manual trigger. Full videos must be native 16:9 and measure 120–300 seconds. Supported full mechanisms: rack-and-pinion, lead screw and eccentric cam. Arbitrary-topic capability is not claimed.

Automatic topic/history reservation, model-written narration, targeted repair, voice caching, shared service coordination, audio mastering, geometry-coupled motion, encoded media checks, evidence sealing and Studio delivery are the new production path. Main runs are allowlisted for bounded outage recovery. Owner approval remains required. Production can reuse a tested component for a different supported concept, while durable history rejects duplicate topics. Test repair configuration and hardcoded old-run cache keys are not promoted.
