# Native visual finish and bounded daily reliability — 2026-11-19

Implementation is staged for cloud verification. This record is not a finished-video claim.

## Visual finish
Daily component shorts render geometry at 1440×2560 and downsample to native 1080×1920 with antialiasing. Directional lighting, broad fill and soft geometry-projected shadows preserve readable small parts. Fonts render at the source resolution. Encoded quality evidence is required and sealed with the actual media. This is not a claim of photorealism or a full-video renderer rollout.

Three representative assemblies extend the unused topic pool: an electromagnetic relay with isolated control and load circuits, a snap-disc thermostat with thermal hysteresis stages, and a rigid spring clothespin with contact-limited fabric gripping. Each has eight causal actions, held-state rules, physical invariant tests, visibility checks and word-timed motion. Electrical fields and slowed thermal/switching action are labeled as illustrations. The unused combination lock is also available; after a successful automatic proof, only three of these four families remain. This is bounded coverage, not unlimited daily capacity.

The system chooses the proof topic. Existing camera-iris, float-valve and all other created families remain permanently blocked. An encoded failure also consumes its family; no corrected rerender bypass is introduced. The fixed Kokoro am_fenrir narrator and manual Studio approval remain unchanged.

## Daily reliability
A quota admission check counts distinct delivered short tags on the Chicago calendar day, not failed attempts. Intended local slots are 03:05, 11:05 and 19:05. Existing fixed UTC cron may arrive later, especially during daylight saving. The existing 15-minute system recovery watcher can reconcile missing due deliveries, serialize generation and request at most six bounded catch-up attempts per day. It waits for active jobs and retained temporary-failure recovery, refuses missing history, and holds when unused visuals run out. It never approves or publishes. Catch-up is feature-gated off until cloud verification; no Codex reminder was created.
